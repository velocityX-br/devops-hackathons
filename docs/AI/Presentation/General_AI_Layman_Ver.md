

1. 多模态模型 (Multimodal Model) —— 维度：数据模态（多模态） 定义：能够同时处理、理解和融合两种或两种以上模态（如文本+图像、文本+音频、视频+文本）数据的模型。
    - 判别式多模态模型：如 CLIP，用于图文匹配（判断这张图和这段文字是否相符）。
    - 生成式多模态模型：如 Sora（文生视频）、GPT-4o（能看图、听声音，并生成文本或语音回答）
 
2. 图像模型 (Image / Vision Model) —— 维度：数据模态（单模态） 定义：专门处理、理解和生成图像/视觉数据的模型。
    - 判别式图像模型：如 ResNet、YOLO，用于图像分类、目标检测（框出图片里的车）。
    - 生成式图像模型：如 Midjourney、DALL-E 3，用于文生图、图像编辑。

3. 生成式模型 (Generative Model) —— 维度：任务目标, 能够学习数据的内在分布规律，并生成全新数据的模型。它的对立面是“判别式模型”（Discriminative Model，如分类器，只负责判断“这是猫还是狗”）。


维度一：按“核心任务与输出目的”分类（最本质的分类）
这是区分模型“到底用来干什么”的维度。除了生成式，还有以下几大核心阵营：
1. 生成式模型 (Generative Models) —— “创造者”
- 任务：学习数据分布，生成全新的、与训练数据类似的数据。
- 输出：文本、图像、音频、视频、代码等。
- 代表：GPT-4 (文本), Midjourney (图像), Sora (视频), Suno (音频)。
2. 判别式模型 (Discriminative Models) —— “分类/预测者”
任务：寻找数据之间的边界，对输入数据进行分类、打标签或预测具体数值。
输出：离散的类别标签（如“猫/狗”）、边界框（Bounding Box）、具体的数值（如房价预测）。
代表：ResNet (图像分类), YOLO (目标检测), 传统的垃圾邮件分类器。
3. 表示/嵌入模型 (Representation / Embedding Models) —— “翻译/度量者”（你提到的遗漏项）
任务：将高维离散数据压缩成低维连续的稠密向量（Embedding），核心目的是计算相似度和信息检索。
输出：固定维度的浮点数数组（如 [0.12, -0.45, ...]）。
代表：OpenAI text-embedding-3, BGE, CLIP (图文对齐端)。
注：它和判别式的区别在于，判别式输出“是/否”，而 Embedding 输出“在多维空间中的坐标”。
4. 决策/强化学习模型 (Decision / RL Models) —— “行动/规划者”
任务：在特定的环境中，通过不断试错（奖励/惩罚机制），学习出最优的行动策略。
输出：具体的动作指令（如“向左转”、“买入股票”、“下一步下在坐标X,Y”）。
代表：AlphaGo (围棋), 自动驾驶中的控制模型, 机器人步态控制模型。
5. 排序/推荐模型 (Ranking / Recommendation Models) —— “筛选者”（工业界主力）
任务：给定一个候选集合，根据用户偏好或相关性对它们进行打分和排序。
输出：相关性分数或排序列表。
代表：抖音/TikTok 的推荐算法, 淘宝的商品排序模型, 搜索引擎的 PageRank 及后续深度学习排序模型。

当你需要写文章、画图时，你找生成式模型（如 GPT, Diffusion）。
当你需要判断图片里有没有猫、邮件是不是垃圾时，你找判别式模型（如 YOLO, 传统分类器）。
当你需要做语义搜索、搭建 RAG 知识库时，你找 Embedding 模型。
当你需要让 AI 自己操作电脑、调用 API 完成复杂任务时，你构建的是 AI Agent（智能体）。
